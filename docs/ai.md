# Optional AI and consent

NetPro supports OpenAI Chat Completions, Gemini's OpenAI-compatible API, and custom compatible base endpoints. Choose a model identifier; none is mandatory. The provider must support `response_format: {type: "json_object"}`. Responses must be a JSON object containing only `matches`, each with a saved `id` and an `evidence` array of supplied field names. Unsupported models and malformed responses fall back to ordinary retrieval with a visible warning.

In Settings, choose provider, enter model and key, and save. Review the data disclosure and saved destination before explicitly consenting. Then test the connection; this sends a fixed synthetic prompt, no contact data. A test still requires consent and may incur a small API charge. Stored credentials are masked. Replace by entering a new key, or use Remove key to remove it and revoke consent. Revoke consent anytime. Changing provider or endpoint discards the old key unless a replacement is supplied and always requires renewed consent.

### Recommendations checked September 30, 2026

- **OpenAI `gpt-4.1-mini`** is a suitable low-cost starting point: the official model page lists **$0.40 input and $1.60 output per million text tokens** (standard pricing), and structured output support. This is a paid API, separate from any ChatGPT subscription. [Official model and pricing](https://developers.openai.com/api/docs/models/gpt-4.1-mini), [structured output documentation](https://developers.openai.com/api/docs/guides/structured-outputs).
- **Google `gemini-2.5-flash-lite`** has a listed free tier for text inputs and outputs, subject to account, region and model-specific quota availability. Its listed paid rates are **$0.10 input and $0.40 output per million tokens**. The free-tier pricing table says data is used to improve Google's products; paid tier says no. Carefully review this before sending personal network data. [Official pricing](https://ai.google.dev/gemini-api/docs/pricing), [OpenAI compatibility](https://ai.google.dev/gemini-api/docs/openai), [rate limits](https://ai.google.dev/gemini-api/docs/rate-limits).

Prices and free tiers can change or disappear. Quotas vary; check the provider account and current documentation rather than relying on a universal requests-per-day value. These recommendations were verified against official documentation, **not through a live paid model call**. You can use another compatible model. NetPro does not enable web grounding, web search, or provider tools.

The provider sees the query, bounded prior query, owner profile, and up to 12 locally retrieved contacts' relevant evidence fields. Contact methods are not included in candidate data. Names are included as evidence only when a name matches the query. Emails, URLs, recognized phone patterns, and exact known method values are redacted from free text. Redaction cannot recognize every possible sensitive fact or unusual contact format. Review owner background and notes before enabling AI. Provider processing and retention are governed by its policies; the app does not promise zero retention.

The model selects IDs and evidence; it does not supply the prose, names, phone numbers or other rendered contact details. NetPro derives direct/tentative ordering locally and shows recorded evidence from the database. This deliberately conservative design prevents model-generated unsupported explanations. Ordinary retrieval remains available at all times.
